# Hello there!

I'm Daniel Molares, a full-stack software developer working for the University of Central Florida.

## What I Do
I frequently work on apps that are useful to faculty and students, and leverage experience in frontend and backend development to better the tools at their disposal. I put a large focus of my time towards maintaining accessibility tools like [UDOIT](https://cdl.ucf.edu/teach/accessibility/udoit/), as well as leading the development of applications like [Intelligent Course Search](https://canvas-lti.cdl.ucf.edu/intelligent-course-search/).
